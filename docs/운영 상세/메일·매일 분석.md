  - **조회 속도**(2026-11-09 @155 담당자 「조회수 속도에 대한 분석도 콘텐츠 분석에」): 서버 `loadSpeed_`가 「게시물 시간별」에서 올린 지 1·3·6·24시간에 가장 가까운 기록(허용 ±0.5·0.75·1·2시간)을 「게시물 일별」 미디어 ID → 주소로 게시물에 붙임(`it.sp` = [[경과 시간, 조회, 도달] | null × 4], 인스타·hong, 10/20 이후 게시물만, 올린 다음 날 08시 기록부터 연결). `ana.js` `speed`: 같은 채널·형식 같은 시간 조회 중간값(나 빼고 3개 이상) 대비 배수 + 기록된 것 중 조회 순위, 캐러셀은 도달 배수도. 판정 문장에 「첫 3시간 …」(14일 확정 줄엔 안 씀), 보드 「첫 N시간」 칸(`.an-cells.five`)·같은 형식 4개 이상 중 3위 안이면 아랫줄 순위, 아침 메일 「조회 속도」 표. 순위는 「역대」가 아니라 10/20 이후 기록 안에서
- **밤 10시 성과 브리핑 메일**(2026-10-19, `nightBrief`): 매일 22:00 트리거(`setupNightBrief`로 등록)가 오늘 올린 인스타·hong·유튜브 게시물 값을 API로 바로 받아 스크립트 속성 `BRIEF_TO`(받는 주소, 코드에 넣지 않음)로 HTML 메일을 보내요. 편집기 `testNightBrief` = 제목에 「(테스트)」, `nightBrief` = 정식. 메일을 먼저 보내고 「당일 22시 기록」 탭에 그날 밤 값을 쌓아요(시트 타임아웃이어도 메일은 나감).
  - 맨 위 「오늘의 반응 순위」 = **반응률** 평소 대비 순위. 반응률 = 인스타 (좋아요+댓글+공유+저장) ÷ 도달, 유튜브·hong (좋아요+댓글) ÷ 조회수. 다만 올린 직후엔 팬이 먼저 봐서 높게 나오는 편(릴스 19시 3.1% → 22시 2.8%)이라 부제는 「내일 다시 봐요」.
  - **표본 기준**(2026-10-21, 「조회 52·좋아요 3으로 대박」 지적): 인스타 도달 300·유튜브·hong 조회 100 미만(`BRIEF_RX_MIN` = 보드 오늘 칸 `TD_MIN`)은 판정 칩 대신 회색 「모으는 중」, 강점·약점·1등·「잘 됨 이상」 칸에서 뺌. 셋째 줄에 조회·n시간째를 같이 써서 「반응은 평소인데 조회가 적은」 게시물이 보이게. 배수는 늘 「배」(%와 섞지 않음, 0.1배 미만은 「0.1배 미만」).
  - 판정 칩: 평소의 0.7배 미만 낮음 · 1.3배 미만 평소 수준 · 2배 미만 잘 됨 · 5배 미만 아주 잘 됨 · 그 이상 대박. 막대는 2배를 넘으면 꽉 차서 안 씀. 강점은 1.3배 이상, 약점은 0.7배 미만일 때만.
  - 평소 = 같은 채널·형식 최근 1년·게시 14일 이상(광고 제외) 중간값, 보드 응답 캐시에서 계산. 팔로우·프로필 활동(도달 1천 명당)·릴스 평균 시청의 평소는 「인스타 게시물 추가」 탭. 조회수는 다 늘어난 평소와 견주므로 못 미치면 「아직 느는 중」. 「당일 22시 기록」이 같은 형식 5개(`BRIEF_MIN`) 쌓이면 조회수는 올린 날 밤끼리 비교.
  - 유튜브 분석 API(시청 시간·구독)는 1~2일 늦어 메일에 없음. 메일 문구는 「화면 문구·디자인 원칙」을 따르고, 「평소」에는 늘 지표 이름을 붙여요(「조회수 평소의 13%」).
